Explanation

Overall Struture

The html incorporates a header - top navigation, a main - game contents, and a footer - credited group members. Multiple sections in the main container are included in the html structure with different class and id. Div containers are placed inside the section to better apply CSS and JavaScript to different levels of containers. Every page is linked together through the top navigation bar and the quiz section at the end of each page, which enables users to swap between pages easily. Among four subpages, Courses and Battles pages, and Items and Characters pages are structured in a similar way.

CSS Animation

Animation including transform and @key-frames are applied in various elements to increase the dynamics of the page and user experience and interaction.

Spinning Icon

Ease-in Character

Bouncing Effect

Glowing Item

The icon of courses cup are used as a background image to enrich the dynamic, which utilises rotate function to achieve the slowing spinning effect.

There is a slidering effect in the character using @keyframes showCharactrer to align with the game concept as if the character drives in.

The modeChoice list pulses using @keyframes pulse, attracting users attentions in this way and enabling them to click on in battles page for more information.

The itmes and characters will glow on hover through the yellow box-shadow and transform: scale, enhancing visual interest while showcasing the name.

Javascript Functions

Javascript in Homepage

The welcome alert comes up when a user first goes into the website through alert, which checks localStorage.getItem('visited') in order to show the code only once, enhancing user experience to avoide repetition.

Date at the top left corner is displayed thorugh const dateDisplay, which changes everyday using the new Date() element.

The backToTopBtn triggers window.scrollTo({ top: 0, behavior: 'smooth' }) by clicking the button, allowing users to go back to the top of the page effortlessly at any time,

Users can browse different equipments by clicking the prevBtn and afterBtn dynamically, which will make function updateEquipment work to update image and content into view.

Javascript in Subpages

Hover to see explanation of each image.

An automatic scrolling gallery is used in courses and battle pages. The scrollSpeed and scrollDelay is set for the autoScroll functioon, which allows the gallery to loop infinitely when it reaches the end.

Pointers added a clickable effect to all card images to show a popup with four track images, which are loaded from the cupNames array. Popup closes when clicking the close button in the right corner.

An interactive hover effect is applied to each item and character. The mouseenter shows the overlay and highlight of the hovered item and character; the mousemove fixes the position of the description box; the mouseleave stops all effects when the mouse moves away.

The function showOverlay(id) displays the overlay image with the matching id while hiding others. The addEventListener('click') is used to make any part of the mode list clickable and trigger the popup.

Start Quiz Button

startQuizBtn

  • Role: Starts the quiz interaction.
  • JS Function: Listens for the click event to hide the intro introPage.style.display = 'none' and show the quiz quizPage.style.display = 'block'.
  • Effect: Initializes quiz state variables score and currentQuestionIndex, clears previous histories, and calls showQuestion(0) to display the first question.

Submit Button

startQuizBtn

  • Role: Submits the current answer for checking.
  • JS Function: Disabled by default; enabled only after a valid input or answer selection. On click, JS validates the answer correctness, updates score, shows feedback, disables itself, and reveals the Next button.
  • Effect: Controls quiz progression step-by-step, preventing moving forward without an answer.

Next Button

startQuizBtn

  • Role: Moves to the next question or finishes the quiz.
  • JS Function: Hidden initially, shown only after submitting an answer. On click, increments currentQuestionIndex, calls showQuestion() again, or calls showResult() if quiz is complete.
  • Effect: Manages quiz navigation and enforces order of questions.
